# Strategy

1. Product fit: publication integrity is the trust boundary between CI-OS
   evidence and the teams expected to act on it.
2. Target job: let operators and business readers know that every visible
   artifact belongs to one complete, current, safe run.
3. Trade-off: defer Scout, demand, recommendation, and UI expansion until the
   release evidence can be trusted.
4. Key metric: the planted-defect matrix rejects every defect and one real
   Hermes run passes publication integrity without moving a blocked decision
   pointer.
5. Defensibility: the value is an auditable evidence-to-decision contract, not
   merely a static dashboard deploy.
