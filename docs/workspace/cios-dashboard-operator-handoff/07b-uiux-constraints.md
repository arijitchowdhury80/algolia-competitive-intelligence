# UI/UX Constraints

Source checked:

- UIUXDesignSOP index was available only under the local Google Drive trash path. It confirms the emphasis-tier model, WCAG 2.2 AA expectations, and Algolia brand toggle with Sora / `#003DFF`.
- The expected Algolia design-system directory named in `AGENTS.md` was not present at the remembered path during this run.

Applied constraints:

- Every element has a tier: readiness is Hero; next action and blocker are Primary; brief bullets are Secondary; artifact refs are Supporting.
- No more than one Hero in the operator handoff block.
- No new decorative cards inside cards. The handoff is a compact section within the existing proof-chain flow.
- Public dashboard remains read-only. Admin write actions may be named, but should not be implied as anonymous public writes.
- Responsive behavior must follow existing dashboard breakpoints and not introduce fixed-width text overflow.
- Accessibility: status cannot rely on color alone; text labels must carry state.
- Tone: plain operational language. No hype, no generic AI phrasing.

Chosen aesthetic:

- Existing Argus cockpit system with Algolia status language. This is a continuity slice, not a new visual identity pass.
