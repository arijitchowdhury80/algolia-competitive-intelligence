# UI/UX Constraints

The referenced UIUXDesignSOP file was not present at the documented local path in this environment, so this slice uses the project and developer constraints already loaded in the session.

Applicable constraints:

- This is an operational admin surface, so use dense, scannable information rather than marketing layout.
- No nested cards. Add a single section consistent with the existing admin page.
- Use sentence case labels.
- Keep visible information bounded: status, report/date, prioritized targets, Scout artifact count.
- Long URLs and paths must wrap.
- Mobile behavior follows the existing admin page table/form reflow.
- Do not invent green status. Missing metadata must render as an empty/degraded state.
