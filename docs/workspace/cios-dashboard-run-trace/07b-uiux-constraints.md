# UI/UX Constraints

The external UIUXDesignSOP file was not present at the documented local path in this environment. This slice follows the loaded project and frontend constraints.

Applied constraints:

- The run trace is supporting trust evidence, not a new hero.
- Keep it compact and scannable.
- No nested cards.
- No fake green states.
- Long source URLs and artifact paths stay out of the visible first-pass UI.
- Render an honest empty state when no product-market run trace exists.
- Preserve existing cockpit visual system rather than introducing a new aesthetic.
